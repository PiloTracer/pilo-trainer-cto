# Glossary — executive & fractional-practice vocabulary

Terms a seasoned engineer meets for the first time at the exec/advisory layer. Plain
definitions, no filler. `@cto-mentor` defines these on first use in a session (per
`standards/mentoring.md`); learners re-read here instead of asking twice.

| Term | Meaning |
|------|---------|
| **ADR** (Architecture Decision Record) | A short written record of one decision: context, options, choice, consequences. The unit of decision hygiene — see `standards/decision-record.md`. |
| **Air cover** | A senior person using their authority to shield you from political pressure while you execute — deflecting complaints, backing your call publicly. Military metaphor: aircraft protecting ground troops. |
| **Baseline** | The measured current state, taken before any improvement target is set. Targets committed before a baseline exists are fiction. |
| **BLUF** | Bottom Line Up Front — the conclusion in the first two lines, reasoning after. US military staff-writing convention, now standard in exec communication. |
| **Board deck** | The slide document a CEO presents to the board of directors. A fractional CTO's technical material rides in its appendix; the CEO presents it. |
| **Charter (engagement charter)** | The one-page contract of a fractional seat: what you own / advise / escalate, scope boundaries, success criteria, exit criteria. Rides as an appendix to the SOW. |
| **Decision rights** | Who is allowed to decide what. Written down, they end "I thought that was my call." |
| **Eng** | Engineering — the org or function. "Eng status" = the state of the engineering work (what ships, what's blocked, what breaks next), not the status of individual engineers. |
| **Feature freeze / code freeze** | A temporary halt to new features (or all new code) so a riskier piece of work — a migration, a launch — gets the team's full attention. A pause, not a cancellation. |
| **Fractional CTO** | A CTO engaged part-time (days per month, hours per week) across one or more clients. Sells outcomes and decisions, not hours. |
| **Handoff pack** | The deliverables a departing advisor leaves behind: roadmap, decision log, operating cadence docs, open risk register, hiring pack. |
| **Interview rubric** | The written, scored criteria each interviewer uses, so "good candidate" is decided against dimensions, not gut feel. |
| **Job spec** | The written role description for a hire: scope, requirements, reporting line, success expectations. The document a recruiter works from. |
| **Own / Advise / Escalate** | The three modes of a charter row. **Own** = you decide and are accountable within agreed bounds. **Advise** = you recommend, the named client role decides. **Escalate** = you flag to CEO/board; no silent carry. |
| **Reversal trigger** | The named, observable fact that would force a decision to be re-opened. The test of whether a decision was real. |
| **Sandbagging** | Deliberately under-committing so targets are always hit. Sustained 100% sprint-goal completion is sandbagging, not excellence — the metric that matters is predictability. |
| **Scope creep** | The slow expansion of an engagement beyond its written scope. The failure mode a charter exists to kill. |
| **Sev1** | The highest incident severity: service down or data at risk, all-hands response. |
| **SOW** (Statement of Work) | The contract document defining an engagement's scope, term, fee, and deliverables. |
| **Status theater** | Updates that perform activity without changing anyone's knowledge or forcing a decision. The anti-pattern the BLUF update format exists to prevent. |
| **Triage** | Sorting by consequence under scarce attention — from emergency medicine: treat where it changes the outcome, and be able to defend what you did not treat. |
| **VP Eng** | VP of Engineering — the full-time engineering leader a fractional seat often prepares the org to hire. The hiring pack is: job spec + interview rubric + 90-day plan. |
