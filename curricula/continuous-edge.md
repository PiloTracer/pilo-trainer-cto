# Continuous Edge

**Slug:** `continuous-edge`  
**Duration:** Ongoing (monthly cadence)  
**Level:** Any — pairs with other programs

## Audience / level assumptions

- Already past the basics, or running this alongside a primary program
- Wants currency without becoming a consumer of trend content
- Most likely failure mode on entry: an unread bookmark pile mistaken for learning

## Duration & cadence

Ongoing, monthly. One `@cto-update run` per month, one drill per quarter minimum.

## Outcomes

- Living backlog of high-signal sources
- Monthly update ritual with practice implication
- Avoid trend addiction; keep durable principles

## Modules

### M1 — Source system
- Objectives: Install the `@cto-sources` + `@cto-update` habit; start from the framework library rather than a blank page
- Drill: Curate 8 sources for your top gap area, beginning with `references/core-library.md` and its Gaps section
- Sources: `references/core-library.md`; `standards/citation.md`
- Exit check: Every entry has title + author or URL, and a status; no unverified work asserted as fact

### M2 — Monthly edge review
- Objectives: Convert new material into a practice change, or discard it
- Cadence: `@cto-update run` → pick 1 drill or mentor focus
- Artifact: `.work.cto/reports/update-YYYY-MM-DD.md`
- Exit check: Each theme carries a practice implication; anything without one is cut

### M3 — Teach-back
- Objectives: Explain one new idea as a 1-pager for your staff. Teaching is the retrieval test — an idea you cannot explain unaided you do not yet hold.
- Drill: Write the 1-pager closed-book, then check it against the source
- Sources: `standards/mentoring.md` § Retrieval opening
- Exit check: 3 consecutive monthly updates with at least one drill each quarter

## Assessment / rubrics

| Criterion | Pass |
|-----------|------|
| Source hygiene | Citations complete; unverified labelled |
| Signal ratio | Every retained theme has a practice implication |
| Teach-back | Written unaided, then corrected against the source |

Pass = ritual exists and changes behavior; fail = unread bookmark pile.

## Exit criteria (program complete)

Ongoing by design. Reviewed quarterly via `@cto-review status`: three consecutive monthly
update reports plus one drill per quarter, all linked from the task ledger.

## Notes

Fed by `@cto-update`. Install alongside a primary program or alone for seasoned CTOs.
